# Lista De Compras

## Necesidades

Necesitarás la app de Expo Go. Descargala desde la Play Store o desde la App Store.

## Instalación (paso a paso)

1. Abrir la terminal - En Windows, busca "CMD". En Mac o Linux, abrí la "Terminal".
2. Descargar el proyecto - Copia y pega el siguiente comando para bajar los archivos: git clone https://github.com/luchovs/Lista-De-Compras
3. Entrar a la carpeta - Ejecutar el siguiente comando: cd Lista-De-Compras
4. Preparar la app - Instalar los componentes necesarios con este comando: bun install
5. Iniciar la app - Ejecutá el siguiente comando para iniciar la aplicación: bun start
6. Escanear el código QR - Luego del paso 5, aparecerá un QR en la pantalla que deberás escanear y la aplicación iniciará automáticamente (muy importante tener el Expo Go instalado, de lo contrario no funcionará).
